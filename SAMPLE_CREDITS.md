# Sample credits

## ~/.samples/aguitar

Acoustic guitar, chromatic D2–D5 (00_D2 … 36_D5, one file per semitone), from
[nbrosowsky/tonejs-instruments](https://github.com/nbrosowsky/tonejs-instruments) (`samples/guitar-acoustic`).
License: [CC-BY 3.0](https://creativecommons.org/licenses/by/3.0/) — attribution required: "Samples by Nicholas Brosowsky / tonejs-instruments".

## ~/.samples/piano, cello, harp, flute

Chromatic folders built from [nbrosowsky/tonejs-instruments](https://github.com/nbrosowsky/tonejs-instruments)
(`samples/piano|cello|harp|flute`). Notes missing from the source were filled by pitch-shifting the
nearest recording with ffmpeg (piano 0, cello 3, harp 26, flute 27 files).
License: [CC-BY 3.0](https://creativecommons.org/licenses/by/3.0/) — attribution required:
"Samples by Nicholas Brosowsky / tonejs-instruments".

| Folder | Range (real pitch) | Tidal helper |
|---|---|---|
| piano | C2–C6 | `piano` |
| cello | C2–C5 | `cello` |
| harp | C3–C6 | `harp` |
| flute | C4–C7 | `flute` |
